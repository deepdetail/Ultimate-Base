# Claude in Chrome: rooms built from layers (shells, furniture by era, items by level), hangar, stairs and elevators

This replaces `CHROME_ROOM_RUN.md` and the rooms and hangar parts of `CHROME_ROOMS_V2_RUN.md` (its vehicle part is still the one to run for vehicles). What this makes in ChatGPT: 263 pictures.

How the game builds a room from these, so every Level and every era looks different:
1. **Shell**: the empty room for the base's era (walls, floor, ceiling, lighting, no furniture), one per era and shape. Shared by every room, so it is only 28 pictures.
2. **Main furniture by era**: each room's two signature pieces (a bed, a desk, a rack) painted in each era's style, so furniture changes when the base reaches a new era.
3. **Level items**: each room Level adds one item (Level 1 to 5) on top of the last, so all five Levels look different. These suit every era.
The game places the pieces along the back wall and the floor to fit any room size, and repeats beds, tables and racks in wider rooms, so a 1x4 room is a real long room, not a stretched picture. Items are painted alone on a flat green (or magenta) background so the game can cut them out; items with green parts use magenta.

Order: Part A (level items) first, because they show in every era; then B (shells) and C (era furniture), both in the order listed, which puts the eras Phoenix and Dude are in first; then D (hangar) and E (stairs and elevators).

How to use it: open ChatGPT in Chrome, open the Claude side panel, copy everything below the line and paste it in. To continue another day, paste it again and say which number to start from.
