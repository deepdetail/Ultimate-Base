# Claude in Chrome: weapon art (shop view, in-hand view, attack effects, 3D turnarounds)

What this makes in ChatGPT for all 14 weapons (Ninja Stars included): a SHOP picture at one standard angle, a HELD side view the game puts in a character's fist, ATTACK effect sprites, and a 6-view TURNAROUND sheet per weapon to make 3D models from later. It is about 53 images, so ChatGPT's daily image limit will stop it partway; it reports where to pick up.

How the game uses these (why the rules below matter): the game draws a person in layers. Behind the body: the quiver and the weapon in the far hand. Then the body, the outfit and armor, then the head again down to the chin (so a vest collar always sits behind the chin). Then the weapon in the near hand, then that hand's fist again, so the fingers wrap the grip. So weapon pictures must show the weapon alone, with no hands or people, and with the grip fully visible.

How to use it: open ChatGPT in Chrome, open the Claude side panel, copy everything below the line and paste it in. To continue another day, paste it again and say which part and number to start from. When the art lands in Drive, ask Claude to wire it in.

## After the run (for Claude, not for the Chrome panel)
- **Shop pictures** replace the current shop icons one for one. **Held pictures** replace the in-hand art; because every grip sits at the image center, each weapon's grip point becomes (0.5, 0.5) and only its size and angles need tuning.
- **Attack effects** go into the battle effects layer (light blending on black). The attack poses themselves come from the character sheets (panel 10 hold pose, plus attack poses when those exist), so the in-hand angles get set per pose then.
- **3D, the second workflow:** feed each turnaround (or its side and three-quarter panels) to an image-to-3D tool and export GLB files (around 30,000 triangles and 2K textures at most), named `weapon_<key>.glb`, into Drive BASED Art/Weapons3D. The game already bundles three.js r128 for the Hangar showroom, so the Weapon Shop can get a spin-around 3D view with the same loader. From the models, the game can also render each weapon in every direction (8 angles, plus the shop and held views) so every picture matches exactly.
