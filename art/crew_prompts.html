Crew sheet prompts

  1. Start a new ChatGPT chat for each character.
  2. Attach the two Commander sheets, then paste Prompt 1.
  3. Only if something is off, use a backup prompt or a fix line in the same chat.
  4. Save with the download arrow on the image and rename it to the save name.
