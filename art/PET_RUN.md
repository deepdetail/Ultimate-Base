# BASED Commander: Pet Art Run (ChatGPT), with breeds

Send the STYLE LOCK as the first message of a new ChatGPT chat, together with the two approved Commander sheets (style_sheet_teal_m.png and style_sheet_orange_f.png). Then send ONE prompt per message and wait for each image. Start a fresh chat and resend the STYLE LOCK every 6 images, or as soon as the style drifts.

## STYLE LOCK (send first)

These two character sheets are the approved art style for my kids' mobile game BASED Commander. Keep this exact style for everything I ask next: realistic anime, clean dark line art, detailed cel shading, light from the upper left. I'm making the crew's pets. Rules for every image: one animal only, full body, standing on all fours (or perched or hovering where the prompt says), body turned three quarters toward the RIGHT, the whole animal visible including tail, ears and wings, a little space around it, plain solid pure green background (#00FF00), no shadow on the ground, no checkerboard, no text, no logos, no collars with words, no borders, no panels. Friendly and loyal looking, never scary: mouth closed or a small happy pant, no fangs showing, no blood. Each pet wears one small piece of base gear in gunmetal with a teal (#2FD4D9) light: a harness, collar tag, leg band or earpiece. Size: SQUARE 1024 x 1024, the animal fills about 70 percent of the frame.

Every prompt below starts with the pet type. Keep the same size, pose and gear for every breed of the same type, so the game can swap breeds without moving anything.

## CHECK each image, send a fix line ONCE if needed

- Wrong background: "Redo it on a solid pure green #00FF00 background, no shadow, no checkerboard."
- Facing left or straight on: "Same pet, turned three quarters to the right."
- Cropped: "Show the whole animal including the tail, with space around it."
- Style drift: "Match the attached style sheets more closely: same line weight and cel shading."
- Too scary: "Same pet but friendlier: mouth closed, softer eyes."
- Breed looks wrong: "Make it look more clearly like a [breed]: [one key trait]."
