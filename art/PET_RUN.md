# BASED Commander: Pet Art Run (ChatGPT)

Each block below is a complete prompt: copy one block, paste it into ChatGPT, wait for the image. Every block carries the full style, so blocks work on their own. For the closest match, attach the two approved Commander sheets (style_sheet_teal_m.png and style_sheet_orange_f.png) in the first message of each chat, and start a fresh chat every 6 images.

SAVE: tap the download arrow on the image itself (the PNG file, not the web page), rename it to the file name in the block, and drop it in Drive: BASED Art / Pets.

If one fails, send ONE fix line: "Redo it on solid flat magenta #FF00FF, no shadow." or "Same pet, turned three quarters to the right." or "Show the whole animal with space around it." or "Friendlier: mouth closed, softer eyes."
